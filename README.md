# 2D Shooter Game

## Overview
The 2D Shooter is a captivating game developed using Processing and Java. The objective is to navigate through various levels, defeating enemies while dodging obstacles. Players can collect power-ups to enhance their abilities and score points.

## Features
- **User-friendly Interface**: Intuitive controls and responsive design.
- **Power-ups**: Various power-ups that improve player capabilities.
- **Multiple Levels**: A range of levels with increasing difficulty.
- **Enemy AI**: Smart enemy behavior that adapts to the player's actions.

## Installation
To run the game, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/jinesh0805/2D-Shooter.git
   ```
2. Navigate to the project directory:
   ```bash
   cd 2D-Shooter
   ```
3. Make sure you have Processing installed. Download it from [Processing.org](https://processing.org/download/).
4. Open the project in Processing and run it.

## Controls
- **Arrow Keys**: Move your character.
- **Space Bar**: Shoot bullets.
- **P**: Pause the game.

## How to Play
- Move around to avoid enemy attacks and shoot them.
- Collect power-ups that appear randomly in the game to gain advantages.
- Defeat all enemies in a level to advance to the next one.
